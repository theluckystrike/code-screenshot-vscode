# Defaults and limits

- `codeScreenshot.scale`, `frame`, `background`, `padding`, `lineNumbers`: the defaults for a new picture. Changes you make in the panel are remembered and win over them.
- `codeScreenshot.fontFamily`: another font for pictures only. Empty uses your editor font.
- `codeScreenshot.maxLines` (1,000) and `codeScreenshot.maxLineLength` (1,000 characters): bigger selections are cut and the panel says so, so a minified file never freezes the editor.
- `codeScreenshot.whenNothingSelected`: the visible lines or the whole file.

Code Screenshot has no account, no telemetry and no network access.
