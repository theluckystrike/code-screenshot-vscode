# Save PNG or SVG

- Save PNG writes a PNG at the scale you picked (1x to 4x).
- Save SVG writes an SVG where the code stays text, so it is sharp at any size and you can select the text.
- Copy SVG puts the SVG code on the clipboard as text.

The file name tells you the lines, for example `app.ts-L12-L40.png`. The dialog opens in the folder you saved to last. Set `codeScreenshot.saveFolder` to always use one folder, and turn off `codeScreenshot.askWhereToSave` to save without the dialog.
